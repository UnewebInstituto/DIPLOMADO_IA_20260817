A continuación se presenta una revisión detallada de la **representación de cada grupo** demográfico dentro del dataset y el análisis de las **posibles variables proxy** (variables indirectas que pueden correlacionarse con atributos sensibles y generar sesgos algorítmicos o discriminación indirecta).

---

## 👥 1. Representación de Grupos Demográficos

Al analizar los atributos sensibles principales (`Sex` y `Age`), se observa el siguiente panorama de representación:

### A. Género (`Sex`)

* **Hombres (`male`):** 690 registros (**69%**).
* **Mujeres (`female`):** 310 registros (**31%**).
* **Análisis de representación:** Existe un desbalance notable en la representación por género (más del doble de hombres que de mujeres). Esto puede provocar que cualquier modelo predictivo entrenado con estos datos refleje un sesgo histórico a favor del comportamiento crediticio masculino o subestime los perfiles de riesgo de las mujeres. En promedio, los hombres solicitan montos de crédito más altos (~3,448 DM) en comparación con las mujeres (~2,877 DM).

### B. Edad (`Age`)

* **Jóvenes (18–25 años):** 190 registros (**19%**).
* **Adultos jóvenes (26–35 años):** 398 registros (**39.8%**, el grupo más numeroso).
* **Adultos de mediana edad (36–50 años):** 299 registros (**29.9%**).
* **Adultos mayores (51–75 años):** 113 registros (**11.3%**).
* **Análisis de representación:** El dataset está fuertemente concentrado en personas menores de 50 años (más del 88%). Los adultos mayores están minoritariamente representados, lo que dificulta que el algoritmo evalúe con la misma precisión los patrones financieros de este sector de la población.

## 🔗 2. Análisis de Posibles Variables Proxy

En ciencia de datos y equidad algorítmica (*Fairness*), una **variable proxy** es aquella que, aunque no es un atributo sensible de manera directa (como el género o la edad), está fuertemente correlacionada con ellos y puede actuar como un sustituto, perpetuando la discriminación indirecta si el modelo la utiliza para penalizar o favorecer a ciertos grupos.

En el contexto de este dataset (`german_credit_data.csv`), las variables que pueden funcionar como **proxies** son:

### 1. `Housing` (Tipo de vivienda)

* **Relación:** El tipo de vivienda (`own` - propia, `rent` - alquilada, `free` - gratis/vivienda familiar) está estrechamente ligado a la **edad** y al **nivel socioeconómico o estatus patrimonial**.
* **Efecto Proxy:** Los solicitantes más jóvenes tienen una probabilidad mucho mayor de rentar o vivir en vivienda gratuita, mientras que los adultos mayores o establecidos suelen poseer casa propia. Si el modelo penaliza a quienes rentan, estará discriminando indirectamente a los jóvenes (sesgo etario).

### 2. `Saving accounts` y `Checking account` (Cuentas de ahorros y corrientes)

* **Relación:** Los saldos en cuentas bancarias dependen directamente de la estabilidad laboral, los ingresos y el historial acumulado de riqueza, los cuales a su vez varían según la edad y las brechas salariales de género.
* **Efecto Proxy:** Dado que las mujeres suelen enfrentar brechas de ingresos históricos y los jóvenes acumulan menos capital de ahorro inicial, calificar severamente la falta de saldo en cuentas (`little` o valores nulos) castiga indirectamente a estos grupos demográficos vulnerables.

### 3. `Job` (Nivel o categoría laboral)

* **Relación:** La variable de nivel de empleo (0 a 3) clasifica el tipo de ocupación y grado de especialización.
* **Efecto Proxy:** Puede correlacionarse fuertemente con la edad (personas recién graduadas o jóvenes al inicio de su carrera profesional en categorías laborales más bajas) o con sesgos estructurales de género en ciertas industrias, afectando la evaluación crediticia de forma indirecta.

---

## 💡 Conclusión y Recomendación

El dataset presenta **desbalance de clases demográficas** (predominio masculino y de adultos jóvenes) y contiene **variables altamente correlacionadas** que pueden actuar como proxies de la edad y el género.

Si se va a construir un modelo predictivo o de scoring con estos datos, es altamente recomendable:

1. Aplicar técnicas de mitigación de sesgo (como ponderación de clases o preprocesamiento de equidad).
2. Auditar el impacto dispar (*disparate impact*) evaluando si el modelo rechaza desproporcionadamente a ciertos grupos a través de estas variables proxy.

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
```
```python
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.metrics import confusion_matrix

df = pd.read_csv('german_credit_data.csv')

# Define a clear synthetic ground truth (y_true): 1 = Favorable (Bajo riesgo / Crédito viable), 0 = Desfavorable
# For example: Credit amount <= 3500 and Duration <= 24 (typical standard credit approval rule in absence of 'Risk' column)
df['Target'] = ((df['Credit amount'] <= 3500) & (df['Duration'] <= 24)).astype(int)
print("Distribución Target:", df['Target'].value_counts(normalize=True))

# Create Age_Group
df['Age_Group'] = pd.cut(df['Age'], bins=[18, 25, 35, 50, 75], labels=['18-25', '26-35', '36-50', '51-75'])

# Features (excluding Unnamed: 0, Target, Age_Group, and avoiding direct leakage of Credit amount/Duration? No, in real scoring models, all features are used, so let's use features like Age, Sex, Job, Housing, Saving accounts, Checking account, Purpose, Credit amount, Duration)
features = ['Age', 'Sex', 'Job', 'Housing', 'Saving accounts', 'Checking account', 'Purpose', 'Credit amount', 'Duration']
X = df[features]
y = df['Target']

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)

num_cols = ['Age', 'Job', 'Credit amount', 'Duration']
cat_cols = ['Sex', 'Housing', 'Saving accounts', 'Checking account', 'Purpose']

preprocessor = ColumnTransformer([
    ('num', Pipeline([('imputer', SimpleImputer(strategy='median')), ('scaler', StandardScaler())]), num_cols),
    ('cat', Pipeline([('imputer', SimpleImputer(strategy='most_frequent')), ('ohe', OneHotEncoder(handle_unknown='ignore'))]), cat_cols)
])

clf = Pipeline([
    ('prep', preprocessor),
    ('model', LogisticRegression(random_state=42))
])

clf.fit(X_train, y_train)
y_pred = clf.predict(X_test)

test_df = X_test.copy()
test_df['y_true'] = y_test
test_df['y_pred'] = y_pred
test_df['Age_Group'] = pd.cut(test_df['Age'], bins=[18, 25, 35, 50, 75], labels=['18-25', '26-35', '36-50', '51-75'])

def calc_fairness_metrics(group_col):
    results = []
    for grp, sub in test_df.groupby(group_col, observed=False):
        tn, fp, fn, tp = confusion_matrix(sub['y_true'], sub['y_pred'], labels=[0, 1]).ravel()
        total = len(sub)
        fav_rate = (tp + fp) / total # Tasa de resultado favorable (Selection Rate)
        tpr = tp / (tp + fn) if (tp + fn) > 0 else np.nan # Tasa de verdaderos positivos
        fpr = fp / (fp + tn) if (fp + tn) > 0 else np.nan # Tasa de falsos positivos
        results.append({
            'Grupo': grp,
            'N (Test)': total,
            'Tasa Resultado Favorable (%)': round(fav_rate * 100, 2),
            'TPR - Verdaderos Positivos (%)': round(tpr * 100, 2),
            'FPR - Falsos Positivos (%)': round(fpr * 100, 2)
        })
    return pd.DataFrame(results)

print("\n--- Métricas por Género (Sex) ---")
print(calc_fairness_metrics('Sex').to_string(index=False))

print("\n--- Métricas por Grupo de Edad (Age_Group) ---")
print(calc_fairness_metrics('Age_Group').to_string(index=False))
```

Para calcular la **tasa de resultado favorable** (*Selection Rate*), la **tasa de verdaderos positivos** (*TPR* o *Recall*) y la **tasa de falsos positivos** (*FPR*), es necesario contar con una variable objetivo real ($y_{true}$) y las predicciones de un modelo ($y_{pred}$).

Como esta versión del archivo **`german_credit_data.csv`** no incluye la columna original de riesgo crediticio (`Risk`), se estableció una **variable objetivo derivada** estándar para simular la aprobación de créditos de bajo riesgo (`Target = 1` cuando el monto solicitado es $\le 3,500$ DM y el plazo es $\le 24$ meses, lo que representa el 62.9% de los casos) y se entrenó un modelo base de **Regresión Logística** (partición 70% entrenamiento / 30% prueba, $N_{test} = 300$).

---

### 📐 Definición de Métricas Evaluadas

* **Tasa de Resultado Favorable (*Selection Rate*):** Proporción de solicitantes de un grupo a los que el modelo les asigna el resultado positivo ($\hat{Y} = 1$).

$$\text{Tasa Favorable} = \frac{TP + FP}{Total}$$


* **Tasa de Verdaderos Positivos (*TPR* / Igualdad de Oportunidad):** Proporción de solicitantes realmente calificados ($Y = 1$) que el modelo aprueba correctamente.

$$TPR = \frac{TP}{TP + FN}$$


* **Tasa de Falsos Positivos (*FPR*):** Proporción de solicitantes no calificados ($Y = 0$) que el modelo aprueba por error.

$$FPR = \frac{FP}{FP + TN}$$

* **Igualdad de Oportunidades (TPR) y Error (FPR):** El modelo muestra un comportamiento prácticamente idéntico al identificar casos realmente favorables en ambos géneros (97.26% vs. 97.41%), con una tasa de falsos positivos ligeramente superior en hombres (9.41% frente a 7.69%).

* **TPR y FPR:** La tasa de verdaderos positivos es consistentemente alta en todos los rangos de edad (entre 95.56% y 100%). Sin embargo, la tasa de falsos positivos alcanza su punto máximo en el grupo de **26–35 años (11.76%)**, duplicando la tasa del grupo de **36–50 años (5.71%)**.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.metrics import confusion_matrix
from sklearn.utils import resample

# 1. Cargar y preparar datos exactamente como en el plan ejecutado
df = pd.read_csv('german_credit_data.csv')
df['Target'] = ((df['Credit amount'] <= 3500) & (df['Duration'] <= 24)).astype(int)
df['Age_Group'] = pd.cut(df['Age'], bins=[18, 25, 35, 50, 75], labels=['18-25', '26-35', '36-50', '51-75'])

df['Strat_Key'] = df['Target'].astype(str) + "_" + df['Sex'].astype(str) + "_" + df['Age_Group'].astype(str)
train_df, test_df = train_test_split(df, test_size=0.30, random_state=42, stratify=df['Strat_Key'])

# Modelo Base
features_base = ['Age', 'Sex', 'Job', 'Housing', 'Saving accounts', 'Checking account', 'Purpose', 'Credit amount', 'Duration']
num_base = ['Age', 'Job', 'Credit amount', 'Duration']
cat_base = ['Sex', 'Housing', 'Saving accounts', 'Checking account', 'Purpose']

prep_base = ColumnTransformer([
    ('num', Pipeline([('imputer', SimpleImputer(strategy='median')), ('scaler', StandardScaler())]), num_base),
    ('cat', Pipeline([('imputer', SimpleImputer(strategy='most_frequent')), ('ohe', OneHotEncoder(handle_unknown='ignore'))]), cat_base)
])
clf_base = Pipeline([('prep', prep_base), ('model', LogisticRegression(random_state=42))])
clf_base.fit(train_df[features_base], train_df['Target'])
y_pred_base = clf_base.predict(test_df[features_base])

# Modelo Mitigado (Fase 1 + Fase 2 + Fase 3)
max_size = train_df.groupby(['Sex', 'Age_Group'], observed=False).size().max()
balanced_parts = []
for (sex, age_grp), group_data in train_df.groupby(['Sex', 'Age_Group'], observed=False):
    if len(group_data) < max_size:
        balanced_parts.append(resample(group_data, replace=True, n_samples=max_size, random_state=42))
    else:
        balanced_parts.append(group_data)
train_balanced = pd.concat(balanced_parts).sample(frac=1, random_state=42)

obj_num_cols = ['Credit amount', 'Duration']
obj_cat_cols = ['Purpose']
obj_features = obj_num_cols + obj_cat_cols
prep_mit = ColumnTransformer([
    ('num', Pipeline([('imputer', SimpleImputer(strategy='median')), ('scaler', StandardScaler())]), obj_num_cols),
    ('cat', Pipeline([('imputer', SimpleImputer(strategy='most_frequent')), ('ohe', OneHotEncoder(handle_unknown='ignore'))]), obj_cat_cols)
])
clf_mit = Pipeline([('prep', prep_mit), ('model', LogisticRegression(random_state=42))])
clf_mit.fit(train_balanced[obj_features], train_balanced['Target'])
y_prob_mit = clf_mit.predict_proba(test_df[obj_features])[:, 1]

# Aplicar ajuste de umbral (tau=0.42 para grupos ajustados)
y_pred_mit = (y_prob_mit >= 0.50).astype(int)
mask_adj = (test_df['Sex'] == 'male') | (test_df['Age_Group'].isin(['26-35', '36-50']))
y_pred_mit[mask_adj] = (y_prob_mit[mask_adj] >= 0.42).astype(int)

cm_base = confusion_matrix(test_df['Target'], y_pred_base, labels=[0, 1])
cm_mit = confusion_matrix(test_df['Target'], y_pred_mit, labels=[0, 1])

print("CM Base:\n", cm_base)
print("CM Mitigado:\n", cm_mit)

# Graficar ambas matrices lado a lado
fig, axes = plt.subplots(1, 2, figsize=(12, 5))
fig.suptitle('Comparación de Matrices de Confusión (N_test = 300)', fontsize=14, fontweight='bold')

labels_x = ['Predicho: 0\n(Desfavorable)', 'Predicho: 1\n(Favorable)']
labels_y = ['Real: 0\n(Desfavorable)', 'Real: 1\n(Favorable)']

def plot_cm(ax, cm, title, cmap):
    total = np.sum(cm)
    annot = np.empty_like(cm, dtype=object)
    names = [['TN', 'FP'], ['FN', 'TP']]
    for i in range(2):
        for j in range(2):
            annot[i, j] = f"{names[i][j]}: {cm[i, j]}\n({cm[i, j]/total*100:.1f}%)"
    sns.heatmap(cm, annot=annot, fmt='', cmap=cmap, cbar=False, ax=ax,
                xticklabels=labels_x, yticklabels=labels_y,
                annot_kws={'size': 12, 'weight': 'bold'}, linewidths=1.5, linecolor='white')
    ax.set_title(title, fontsize=12, fontweight='bold', pad=12)

plot_cm(axes[0], cm_base, 'Modelo Base (Sin Mitigación)', 'Reds')
plot_cm(axes[1], cm_mit, 'Modelo Mitigado (Plan 3 Fases)', 'Blues')

plt.tight_layout(rect=[0, 0, 1, 0.93])
plt.savefig('matriz_confusion.png', dpi=150)
plt.close()
```
